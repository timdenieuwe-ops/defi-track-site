Support

Help for DeFi Track: LP Portfolio.

Need help?

Open a support issue on GitHub and describe what you were doing, which network or protocol was involved, and what you expected to happen.

Never include a seed phrase, private key, recovery phrase, wallet password or other signing credential. If a wallet address or screenshot is not necessary to explain the issue, leave it out.

Open a support issue

Before reporting a problem

  • Confirm that the wallet address is a valid public address.
  • Pull to refresh and check the network-status message in the app.
  • Remember that supported networks and protocols vary by position type.
  • Historical data may be incomplete for periods before a wallet was first tracked.
  • Widgets and Apple Watch show the latest received snapshot and are not a continuously streaming feed.

What DeFi Track does not do

DeFi Track does not request private keys or seed phrases and does not execute trades. It is an informational, read-only portfolio tracker. It does not provide financial advice.
